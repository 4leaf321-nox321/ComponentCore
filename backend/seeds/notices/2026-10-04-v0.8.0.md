# v0.8.0 업데이트 — 화면 문구를 표준 용어로, 해석 조건에 파트별 설정

■ 화면 문구 — 격식체와 표준 용어로 바꿨습니다
- 꼬리표는 태그, 승격은 등록, 찾기는 검색, 비슷한 것은 유사 형상으로 부릅니다.
- 단추는 명사형(삭제 · 복원 · 다운로드)으로, 설명과 오류는 「~합니다」 체로 맞췄습니다.

■ 해석 조건 › 파트별 설정 — 파트마다 해석을 다르게 다룹니다
- 리본의 「파트별 설정」 표에서 파트마다 변형체 · 강체, 솔리드 · 쉘, 해석 제외, 파트 메시(요소 크기 · 형상 · 차수)를 정합니다. 물성도 같은 표에서 고릅니다.
- 맨 위 「모든 파트」 줄로 한 열을 한꺼번에 바꿉니다. 쉘 파트가 있으면 DOE 가 중간면을 함께 냅니다.
- 메시 힌트는 국부 메시(면 · 엣지 세분화와 「전체」)로 좁혔습니다. 겹치면 좁은 쪽이 우선합니다.
- 없는 파트, 강체이면서 쉘인 파트, 해석에서 제외한 파트에 걸린 조건은 저장할 때 알려 드립니다.
