# v0.36.0 업데이트 — MatNexus 카드의 소성 곡선, 하중 단계 점검

■ 새로 생긴 것
- **MatNexus 카드에서 소성 곡선 가져오기:** 모델 트리의 물성 항목에서 재료 모델을 다선형 소성으로 두고 ‘MatNexus 카드에서 가져오기’를 누르면, 그 재료의 인장 시험 카드가 방향(MD, TD 등)마다 표시됩니다. 확정된 카드만 ‘이 곡선 사용’으로 가져올 수 있으며, 초안이나 내려진 카드는 까닭이 함께 표시됩니다. 가져온 곡선에는 카드, 방향, 받은 때가 출처로 남습니다. 표를 직접 고치면 직접 입력한 곡선이 됩니다.

■ 바뀐 것
- 하중 단계, 시간별 배율, 적용 단계는 다른 케이스와 잇지 않은 정적 케이스에서만 지정할 수 있습니다. 이은 케이스에 지정하면 저장할 때 까닭을 알려 줍니다. ‘이어지는 케이스 추가’는 하중 단계를 옮기지 않습니다.
- 다선형 소성 표의 마지막 점 뒤는 그 응력 그대로(완전 소성) 계산됩니다.

■ 확인해 주십시오
- 이미 저장된 조건 가운데 다른 케이스와 이은 케이스에 하중 단계, 시간별 배율, 적용 단계가 있으면 다음 저장 때 막힙니다. 그 케이스를 다른 케이스와 잇지 않거나 단계를 지우십시오.
