# v0.26.0 업데이트 — 해석 조건의 접촉 검사: 접촉 미정의 인접 바디를 찾습니다

■ 해석 조건 › 접촉 검사 — 빠진 접촉을 위치와 함께 알려 드립니다
- 조립의 인접 바디를 접촉 면적 · 위치와 함께 찾고, 정의한 접촉과 비교해 접촉 미정의 바디를 보여 줍니다. 모서리만 닿은 바디와 해석 제외 파트는 뺍니다.
- 「미정의 접촉을 본딩으로 생성」 을 누르면 접촉 미정의 바디의 인접 면으로 선택 그룹과 본딩(Tie) 접촉을 만듭니다.
- 모달 · 조화 응답 해석에서는 마찰 · 거친 접촉이 본딩처럼, 마찰 없음 · 분리 없음 접촉은 미끄러지는 것으로 풀린다고 안내합니다. 미끄러지는 접촉으로만 이어진 바디는 0 Hz 모드가 생길 수 있다고 알려 드립니다.
- 해석 플랫폼으로 내보내는 점 파일에 인접 바디 목록이 추가되고, 접촉 미정의 바디가 있으면 점 파일과 표에 경고가 남습니다.

■ 고친 것
- 미세 간극의 위치가 0, 0, 0 으로 나오던 경우를 고쳤습니다.
