# v0.35.0 업데이트 — 해석 쪽이 받는 판에 맞춰 내보내기

■ 바뀐 것
- 해석 케이스가 여럿인 조건, 하중 단계, 소성은 해석 쪽(SimEngBay)이 그 판을 받을 때 DOE로 내보냅니다. 받는지 여부는 ‘서버’ 화면의 ‘해석 쪽 능력표’로 판단하므로, 해석 쪽을 새 판으로 올린 뒤 시스템 관리자가 능력표를 갱신하면 바로 적용됩니다.
- 대상 솔버를 지정하지 않은 해석 케이스에 하중 단계, 시간별 배율, 적용 단계, 소성이 있으면 해석 쪽의 모든 솔버가 받을 때만 DOE를 생성합니다. 받지 않는 솔버가 있으면 DOE를 생성할 때 까닭을 알려 줍니다. 그 케이스에 받는 솔버를 대상 솔버로 지정하십시오.

■ 확인해 주십시오
- 운영자: .env의 DOE_CONDITIONS_V2는 이제 auto(기본), on, off 중 하나입니다. 기존 값 true, false는 on, off로 읽습니다. 특별한 까닭이 없으면 지정하지 않거나 auto로 두십시오.
