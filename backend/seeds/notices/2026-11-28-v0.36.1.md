# v0.36.1 업데이트 — 공지 본문 표시 고침, 해석 쪽 v0.38.1 확인

■ 고친 것
- 공지 본문에서 여러 줄에 걸쳐 별표 두 개(**)나 역따옴표(`)로 감싼 글이 굵은 글씨나 코드로 표시되던 것을 고쳤습니다. 이제 한 줄 안에서 짝이 맞을 때만 그렇게 표시됩니다. 지금까지 나간 공지에는 이런 글이 없어 보이는 모양은 같습니다.

■ 바뀐 것
- 해석 쪽(SimEngBay) v0.38.1의 능력표로 확인했습니다. 이 판부터 정적 해석에서 하중 단계, 시간별 배율, 적용 단계와 이선형·다선형 소성을 두 솔버(CalculiX, Ansys) 모두 받습니다.

■ 확인해 주십시오
- 해석 쪽을 v0.38.1 이상으로 올린 뒤 시스템 관리자가 ‘서버’ 화면의 ‘해석 쪽 능력표’에서 갱신하면, 대상 솔버를 지정한 케이스에도 위 항목을 저장할 수 있고 DOE로 내보냅니다. 다른 케이스와 이은 케이스에는 지금처럼 하중 단계, 시간별 배율, 적용 단계를 지정할 수 없습니다.
