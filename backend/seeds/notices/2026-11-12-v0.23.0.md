# v0.23.0 업데이트 — 조립 안에서 그린 형상을 지키고, 계정 메일 주소를 한 번에 복사합니다

■ 조립 — 조립 안에서 직접 그린 형상이 지워지지 않습니다
- 구성품을 옮기기만 해도 조립 안에서 직접 그린 형상이 빠지던 것을 고쳤습니다.
- 「구성」 목록에 「조립 안에서 직접 그린 형상」 이 읽기 전용으로, 3D 와 같은 색으로 보입니다.
- 조립에는 부품을 따로 그려 가져오는 것을 권합니다. AI 도구가 조립 안에 직접 그리면 그렇게 알려 줍니다.

■ 관리 › 계정 — 고른 계정의 메일 주소를 한 번에 복사합니다
- 표에서 계정을 고르고 「메일 주소 복사」 를 누르면 받는 사람 칸에 바로 붙는 꼴(; 로 이음)로 복사됩니다. 메일 주소가 아닌 아이디는 빼고 알려 드립니다.
