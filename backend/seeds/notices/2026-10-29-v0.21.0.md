# v0.21.0 업데이트 — 비슷한 태그 정리, 기본 관계 한 번에, 바디 볼트 예압

■ 관리 › 온톨로지 — 태그와 관계를 정리합니다
- 「비슷한 태그 정리」 가 띄어쓰기 · 이음표만 다른 태그(굽힘시험 · 굽힘 시험)를 묶어 보여 줍니다. 남길 것을 골라 합치면 붙은 곳이 옮겨 가고, 지운 이름은 별칭으로 남습니다.
- 관계 화면의 「CompCore 기본 관계」 로 적용 모델 · 서비스 부품 · 대상 모델 관계를 한 번에 만듭니다. 이미 있는 것은 그대로 둡니다.

■ 해석 조건 — 바디에 볼트 예압을 겁니다
- 바디로 거는 볼트 예압은 좌표계로 단면을 정합니다(Z 축 = 볼트 축, 원점 = 단면 자리). 좌표계가 없으면 저장할 때 알려 드립니다.
- 단면이 볼트 바디를 지나지 않으면 내보낼 때 경고합니다. 해석 플랫폼으로 내보내는 점 파일에 바디 선택 그룹이 추가되었습니다.
