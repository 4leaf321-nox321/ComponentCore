# v0.6.0 업데이트 — DOE 계획 확장, 2D 도면 · 조립 구속 · 판금 펴기, 형상으로 거르기

■ 실험계획(DOE) — 만들기 전에 더 정하고, 만든 뒤 더 봅니다
- 제약식으로 맞지 않는 조합을 미리 거릅니다. 끝 점을 미리 만들어 볼 수 있고, 설계점을 표로 직접 줄 수도 있습니다. Sobol 표본을 지원합니다.
- 측정값(부피 · 크기 · 영역 면적 · 거리 · 식)을 표의 열로 받습니다. 형상 점검이 얇은 벽 · 짧은 모서리 · 좁은 면을 경고합니다.
- 같은 폴더에 설계점을 더하고, 설계점 분포를 그림으로 봅니다. 형상을 여러 개씩 나눠 만들어 생성이 빨라졌습니다.

■ 새 작업 · 내 작업 — 도면과 조립 기능이 늘었습니다
- 2D 도면: 3각법 세 뷰 · 전체 치수 · 구멍표 · 표제란을 PDF · DXF · SVG · PNG 로 받습니다.
- 조립 구속(맞대기 · 면 맞춤 · 동심 · 평행 · 직각 · 각도)을 3D 에서 면을 눌러 겁니다. 치수가 바뀌어도 따라 앉습니다.
- 판금 펴기(레이저용 DXF), 셸 해석용 중간면, 스케치 구속, 곡면과 두께 주기가 추가되었습니다.
- 작업을 복제할 때 해석 조건도 함께 복사할 수 있습니다.

■ 검색 · 실행 기록 — 형상으로 찾고, 도는 작업을 멈춥니다
- 내 작업 · 부품 · 지그 목록을 크기 · 부피 · 구멍 같은 형상 특징으로 거릅니다.
- 실행 기록에서 대기 중이거나 도는 작업을 멈춥니다. 관리 › 서버에서 작업 워커가 살아 있는지 봅니다.
