# 0013. 해석 조건을 케이스 · 등록부 · 능력표로 넓힌다 — 비선형 · 다물체 · 충격을 같은 조건으로

날짜: 2026-11-25
관련: [해석-확장-설계.md](../해석-확장-설계.md)(이 결정의 설계), [해석-조건-설계.md](../해석-조건-설계.md),
[동역학-조건-설계.md](../동역학-조건-설계.md), [ADR 0010](0010-해석-결과는-SimEngBay-가-보여-준다.md)

## 결정

해석 조건을 선형 해석 너머(비선형 정적 · 다물체 동역학 · 충격 · 낙하)로 넓힌다. **조건을 새로 짜지 않고 지금의
모델을 넓힌다** — 사양표로 그리는 화면, 솔버를 모르는 중립 JSON, 설계점마다 다시 푸는 선택 그룹 · 좌표계 ·
`"=식"`, 점 파일 · 픽스처 계약은 그대로다. 넓히는 뼈대는 넷이다.

1. **공유 모델과 해석 케이스 여럿** — 형상 · 재료 · 선택 그룹 · 좌표계 · 연결 · 곡선은 한 벌, 해석은 케이스마다
   (설정 · 하중 · 구속 · 초기조건 · 출력 · 앞 케이스). 지금의 조건 한 벌은 케이스 하나다.
2. **해석 종류 등록부** — 종류마다 받는 항목 · 칸 · 필요한 물성 · 검증을 한 곳에. 칸의 `only_for` 는 손으로
   적지 않고 등록부에서 만든다.
3. **곡선** — 시간 · 단계 · 주파수에 따른 값을 한 종류로. 조화 해석의 주파수 표 · 랜덤의 PSD 표 · 동역학의 구동
   곡선 · 비선형의 하중 이력이 같은 것을 쓴다.
4. **받는 쪽 능력표** — 솔버마다 「받는 종류 · 항목 · 칸 · 재료 모델 · 계약 판」 을 받는 쪽이 낸다. CompCore 는
   케이스의 대상 솔버로 저장 · 내보내기 때 걸러 「이 솔버가 아직 받지 않음」 을 말한다.

**받는 솔버는 CalculiX · Ansys 가 먼저다. 다른 솔버도 붙일 수 있어야 한다**(사용자, 2026-11-25) — 그래서 조건에
솔버의 말을 넣지 않고, 솔버마다 다른 것은 능력표와 받는 쪽의 번역이 맡는다. 새 솔버를 붙이는 일은 능력표 하나와
받는 쪽의 번역이고, CompCore 코드는 고치지 않는 것이 목표다.

**순서**(사용자, 2026-11-25): ① 구조 정리 → ② 비선형 정적 → ③ 다물체 동역학 → ④ 충격 · 낙하.

## 배경

지금 조건은 해석 하나(`analysis`)를 들고, 종류마다 칸이 갈리는 것을 칸 39곳의 `only_for` 목록으로 적는다
(`core/conditions.py` 2,947줄). 시간축은 정적의 `steps` · `substeps` 숫자와 주파수 표뿐이고, 재료는 MatNexus 의
값을 그대로 나를 뿐 어떤 재료 모델로 풀지는 정하지 않는다. 앞선 해석을 잇는 길은 초기조건 `prestress`(선행 정적
해석 이름) 하나다. 비선형 · 동역학 · 충격은 모두 「여러 단계 · 시간에 따른 하중」 「재료 모델」 「해석의 이음」 이
핵심이라, 지금 모양에 칸을 더 붙이면 `only_for` 와 분기가 늘어나기만 한다.

## 대안

1. **해석 종류마다 따로 조건 화면 · 모델** — 가장 어려운 것(형상 · 선택 그룹 · DOE · 물성 · 폴더 계약)이 종류만큼
   생긴다. 동역학 설계(0장)가 이미 기각한 길이다. 기각.
2. **지금 모델에 칸만 더하기** — 1단계 일이 없지만, 단계 · 곡선 · 케이스가 없는 채로 비선형부터 하면 그 셋을
   비선형만의 모양으로 만들고 동역학 · 충격에서 다시 만든다. 기각.
3. **솔버 덱을 조건에 넣기**(솔버별 키워드) — 솔버를 붙일 때마다 조건이 갈린다. 재료의 `deck_formats` 처럼
   「덤으로 함께 내보내는 것」 은 받되, 계약의 정본은 중립 그대로. 기각.

## 지키는 것

- **옛 조건은 그대로 읽히고, 케이스가 하나면 옛 모양(v1) 그대로 내보낸다** — 작업 · 부품 · 지그 · DOE 에 저장된
  조건과 SimEngBay 픽스처 20개(`fixtures/simengbay/`)가 시험의 기준이다. 받는 쪽이 v2 를 받기 전에는 케이스가
  여럿인 조건의 내보내기를 막는다(저장은 된다).
- 경계는 그대로다 — 메시 · 솔브 · 결과는 밖(ADR 0010).
