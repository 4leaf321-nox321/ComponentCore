# 0006. 시험 규격은 코드와 DB 두 곳에 둔다 — 공개 규격은 코드, 사내 규격은 DB

날짜: 2026-10-04

## 결정

시험 규격(시편 치수 · 시험 지그의 배치 규칙 · 해석 기본값)을 **프리셋** 한 모양으로 정하고 두 곳에
둔다.

- **공개 규격(ASTM · ISO)** — 코드. 모양을 만드는 규칙(`core/specimens/bending.py` …)은 파이썬,
  치수 값은 저장소의 데이터 파일(`core/specimens/data/<시험>.json`)이다. 모든 서버에 같은 값이
  릴리스와 함께 들어가고, 프리셋마다 시험(그려 보기 · 조건 검증)이 돈다.
- **사내 규격(사내 시험법 · 고객사 규격)** — DB(`specimen_presets`, 0034). 시스템 관리자가
  화면에서 공개 규격을 복사해 고친다. 저장할 때 코어의 같은 검사와 실제로 그려 보기를 지난다.
- 화면 · API 는 둘을 **한 목록**으로 보인다(`origin` 만 다르다). 코어는 DB 를 모르므로 서버가 사내
  프리셋을 값으로 넘긴다 — 지그 생성은 고른 규격의 규칙(`bending_setup`)을 작업 입력에 스냅숏으로
  담는다.
- 값마다 출처(`source`)를 적고, 규격서와 대조하기 전에는 `verified=false` 로 「검토 필요」 를
  보인다.

## 배경

SpaceClaim 애드인(71_AnsysJigAutoModeler)에 시험 시편 · 시험 지그 프리셋이 약 58종 있었다(C# 코드에
박힌 값). 사용자는 이것을 CompCore 에서 쓰고 싶어 했고, 특히 굽힘 시험의 지그 · 해석 조건이 중요하다고
했다(2026-10-04). 사내 규격도 넣을 계획이다.

조사에서 애드인의 값 일부가 규격과 달라 보였다(D638 Type II 필렛 R12.7 ↔ R76, D1002 겹침 25.4 ↔
12.7, D790 롤러 Ø8 ↔ R5). 그래서 값을 그대로 옮기지 않고 출처와 검토 여부를 함께 든다.

## 대안

| | 코드만 | 공용 부품(규격 사양) | DB 만 |
| --- | --- | --- | --- |
| 값 고치기 | 릴리스가 필요 | 관리자가 바로 | 관리자가 바로 |
| 서버 사이 일치 | 저절로 같다 | 서버마다 가져와야 | 서버마다 다를 수 있다 |
| 잘못된 값 거르기 | 프리셋마다 시험 · CI | 저장할 때만 | 저장할 때만 |
| 조건이 붙은 규칙(16 × 두께, 두께 3 이하면 R2) | 자연스럽다 | 형상 한 벌뿐 — 못 담는다 | 숫자만, 규칙은 결국 코드 |
| 사내 · 고객 규격 | **넣을 수 없다** — 저장소가 공개 | 된다 | 된다 |

- **코드만** — 사내 규격을 둘 곳이 없다. 기각.
- **공용 부품 + 규격 사양**(받침 · 핀 · 클램프의 길) — 프리셋 하나가 도면 하나가 되어 도그본 열두 개를
  따로 그려야 하고, 「지지 간격 = 16 × 두께」 같은 규칙은 형상이 아니다. 구매품(품번 있는 지그 부품)에만
  맞다. 기각.
- **DB 만** — 공개 규격까지 서버마다 심어야 하고(행을 마이그레이션에 넣지 않는다 — AGENTS.md), 값이
  서버마다 어긋나도 모른다. 기각.

## 결과

- 모듈 `specimens`(백엔드 · 화면), 화면 「시험 규격」(공용 공간), MCP `list_test_presets` ·
  `create_specimen_work` · `save_test_preset` · `delete_test_preset`.
- 첫 시험은 **굽힘**: 공개 규격 13종(ASTM D790 16:1 · 32:1, ISO 178, D7264 A · B, D6272 16:1 ·
  32:1, C1161 A · B · C, DMA 장비 예시 둘). 시편 + 지지 롤러 · 로딩 노즈 + 해석 조건(롤러 · 노즈
  강체, 롤러 고정, 노즈 원격 변위, 마찰 접촉, 대칭점 구속, 정적 대변형)이 붙은 내 작업을 만든다.
- 굽힘 지그 생성기(`bending`)가 같은 규칙 함수로 스팬 · 롤러 · 노즈를 정하고 4점 굽힘을 한다.
- 공개 규격의 값을 고치는 길은 코드(릴리스)뿐이다. 틀린 값을 찾으면 사내 규격으로 복사해 바로 쓰고,
  코드는 따로 고친다.
- 다음 시험(인장 · 압축 · CAI · 피로 · 접착 이음)도 같은 모양으로 더한다 — 시험 종류마다 프리셋
  모델 · 생성기 · 데이터 파일 하나.
