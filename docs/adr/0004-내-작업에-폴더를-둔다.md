# 0004. 「내 작업」 에 폴더를 둔다 — 작업이 경로를 들고, 폴더 표는 두지 않는다

날짜: 2026-10-03

## 결정

작업(`works`)이 **폴더 경로** 한 칸(`folder`, `고객A/2026/검사지그`, 빈 것이 맨 위)을 든다.
폴더 표는 따로 두지 않는다 — 폴더는 그 안에 작업이 있을 때 있다(`GET /works/folders` 가 경로에서
나무를 세운다). 꼬리표는 그대로 둔다: 폴더는 작업이 놓이는 **한 곳**, 꼬리표는 **여러 묶음**이다.
연도는 따로 저장하지 않고 만든 날(`created_at`)에서 뽑는다.

## 배경

2026-09-20 에는 「폴더는 두지 않는다 — 한 작업이 여러 묶음에 들 수 있는 꼬리표가 더 맞다」 로
정했다. 작업이 늘자 사용자가 **폴더 구조나 연도로** 나눠 보고 싶다고 했다(2026-10-03). 꼬리표는
거르기에는 좋지만 「어디에 두었나」 를 보여 주지 못한다 — 나무가 없고, 꼬리표를 안 붙인 작업은
어디에도 안 보인다.

## 대안

- **폴더 표(`work_folders`) + 작업의 `folder_id`** — 빈 폴더가 서버에 남고 폴더마다 설명 · 권한을
  둘 수 있다. 그러나 표 하나 · 외래 키 · 이름 바꾸기의 연쇄가 더 들고, 지금 필요한 것(나눠 두고
  보기)에 비해 무겁다. 빈 폴더가 필요해지면 그때 표를 더한다 — 경로를 들고 있으니 옮기기 쉽다.
- **화면에서만(브라우저 저장소)** — 다른 PC · MCP 의 AI 가 볼 수 없다. 기각.
- **꼬리표에 `/` 를 넣어 나무처럼** — 한 작업이 여러 「폴더」 에 들어 나무가 거짓말을 한다. 기각.

## 결과

- 마이그레이션 0023 — `works.folder`(문자열, 색인). 있는 작업은 맨 위.
- API: 목록에 `folder` · `subfolders` · `year` · `order(created)`, `GET /works/folders` ·
  `GET /works/years`, `POST /works/folders/rename`(하위까지 옮기기 · 합치기 — 폴더 지우기는 위
  폴더로 합치기), `POST /works/move`(여럿을 한 폴더로). 경로는 서버가 한 모양으로 다듬는다(8 단계 ·
  이름 60 자).
- 화면: 왼쪽 폴더 나무와 만든 해, 끌어다 놓기 · 골라 옮기기, 연도별로 묶어 보기. **빈 폴더**는
  작업을 넣기 전까지 그 브라우저에만 있다(서버에 표가 없어서).
- MCP: `create_work(folder)`, `list_works(folder, year)`.

## 더한 것 — 공용 공간에도 같은 폴더 (2026-10-03)

부품 · 지그 · 템플릿도 같은 방식으로 폴더를 든다(마이그레이션 0024, `parts.folder` ·
`jigs.folder` · `recipe_templates.folder`). 경로 다듬기 · 「그 폴더와 아래」 거르기 · 나무 세기 ·
폴더째 옮기기는 한 곳(`app/shared/folders.py`)에 두고 네 공간이 같이 쓴다. 화면 조각도 하나다
(`frontend/src/shared/folders/` — 나무, 폴더 창들, 고르기, 끌어다 놓기).

내 작업과 다른 점은 **여럿이 함께 쓴다**는 것 하나다.

- **항목 옮기기**(`POST /{parts|jigs|templates}/move`, PATCH 의 `folder`)는 올린 사람 · 관리자 —
  항목을 고치는 규칙(`require_owner`)과 같다. 하나라도 남의 것이면 아무것도 옮기지 않는다.
- **폴더째 옮기기 · 이름 바꾸기 · 지우기**(`POST …/folders/rename`)는 그 폴더(하위 포함)에
  **남의 것이 섞여 있으면 관리자만**. 내가 고친 폴더 이름이 남의 항목을 옮기기 때문이다.
- 템플릿은 **보이는 것만** 센다 · 옮긴다(내 것 + 공용). 남의 비공개 템플릿은 같은 이름의 폴더에
  있어도 나무에 안 보이고, 내 폴더 이름 바꾸기에 끌려가지 않는다. 내 것 · 공용이 한 나무를 쓰고,
  `GET /templates/folders?scope=` 로 자리마다 센다.
- 처음 승격할 때 부품 · 지그는 **작업의 폴더를 물려받는다**(꼬리표처럼). 카탈로그에서 옮긴 뒤
  다시 승격해도 제자리로 끌고 오지 않는다. 템플릿은 저장할 때 폴더를 받고(그리기 · 작업 화면이
  작업의 폴더를 채워 건넨다), 복사본은 원본의 폴더 · 꼬리표를 가져온다.
- 빈 폴더는 여기서도 그 브라우저에만 있다(공간마다 따로).
- MCP: `list_parts(folder)` · `list_jigs(folder)` · `save_template(folder)`, `recipe_schema` 의
  `saved_templates` 에 `folder`.
