# 시험 규격 — 시편 · 시험 지그 · 해석 조건을 규격 프리셋으로

SpaceClaim 애드인(71_AnsysJigAutoModeler)에 있던 시험 시편 · 시험 지그 프리셋(약 58종)을 CompCore 로
옮기는 일의 설계와 진행. 공개 규격은 코드, 사내 규격은 DB 에 같은 모양으로 둔다(ADR 0006).
굽힘을 「시편 → 시험 지그 → 해석 조건」 까지 끝까지 먼저 하고(2026-10-04), 나머지 시험을 같은 길로
더한다.

## 0. 애드인에 있던 것 (2026-10-04 조사)

| 분류 | 애드인의 종류 | 여기서 |
| --- | --- | --- |
| 굽힘 시편 · 지그 | 3점 7(D790 16:1 · 32:1, ISO 178, D7264, C1161 A · B, DMA) · 4점 5(D6272 16:1 · 32:1, C1161 B · C, DMA) | ✅ 13종(D7264 B 더함) |
| 인장 · 전단 시편 | 25종(E8, D638 I~V, ISO 527-2, E602, D5766, D3039, IPC-TM-650, D5379, D7078 …) + 그립 | 다음 |
| 압축 / CAI | 6 / 3 + 가압판 · 좌굴 방지 가이드 | 그다음 |
| 피로 / 접착 이음 | 6 / 5 | 그다음 |
| 나사 | ISO 262 M1.6~M24(지름 · 피치), 머리 · 너트 · 와셔는 비례 근사 | 레시피의 나사 표(M3~M12, 너트 · 와셔는 실제 표)를 넓힌다 |
| 재료 | 3종 기본값 | **안 옮긴다** — MatNexus · 물성 카탈로그가 있다 |

애드인의 값 일부는 규격과 달라 보였다(D638 Type II 필렛 R12.7 ↔ R76, ISO 527-2 1B R20 ↔ R60, D1002
겹침 25.4 ↔ 12.7, D790 롤러 Ø8 ↔ R5). 그대로 옮기지 않는다 — 프리셋마다 출처를 적고 규격서와
대조하기 전에는 「검토 필요」.

## 1. 프리셋

```jsonc
{
  "id": "astm-d790-16",               // 공개 규격은 이름, 사내 규격은 DB 의 uuid
  "test": "bending", "family": "bend_bar",
  "standard": "ASTM D790", "name": "ASTM D790 3점 굽힘 (16:1)",
  "specimen": {"length": 127, "width": 12.7, "thickness": 3.2},
  "setup": {
    "points": 3,
    "span": {"to_thickness": 16},       // 또는 {"value": 40}
    "load_span": null,                  // 4점: {"to_span": 0.3333} 또는 {"value": 20}
    "support_radius": 5.0,              // 또는 [{"max_thickness": 3, "radius": 2}, {"radius": 5}]
    "nose_radius": 5.0,
    "overhang": {"to_span": 0.1, "min": 6.4}
  },
  "analysis": {"strain": 0.05, "friction": 0.1},   // 해석 기본값 — 규격의 판정 기준이 아니다
  "source": "ASTM D790: …", "verified": false, "note": ""
}
```

- 정본은 `core/specimens/presets.py`(pydantic). 시편 길이가 지지 간격 + 양쪽 돌출을 못 담으면, 4점인데
  하중 간격이 없으면, 두께별 반지름의 마지막 줄이 나머지를 안 맡으면 거절한다.
- 공개 규격: `core/specimens/data/bending.json`. 값을 고치면 `source` 를 같이 고치고, 규격서와
  대조했으면 `verified: true`. **회사 · 고객 규격은 여기에 넣지 않는다** — 저장소가 공개다.
- 사내 규격: `specimen_presets`(0034). 화면 「시험 규격」 에서 관리자가 공개 규격을 복사해 고친다.

## 2. 굽힘 — 시편 · 시험 지그

좌표: 시편 길이 X · 폭 Y · 두께 Z, XY 가운데가 원점, 아랫면 z=0. 지지 롤러는 아래(축 Y, 아랫면에
닿게), 노즈는 위. 바디 이름은 `시편` · `롤러_1` · `롤러_2` · `로딩_노즈`(4점: `로딩_노즈_1` · `_2`)
— 지그 생성기의 이름표와 같다.

레시피 변수가 규칙을 든다 — **DOE 가 두께를 훑으면 따라온다**:

| 변수 | 값 |
| --- | --- |
| `길이` · `폭` · `두께` | 시편 |
| `간격비` · `지지_간격` | `=간격비 * 두께`(간격비 규격) 또는 고정 값 |
| `하중_간격_비` · `하중_간격` | 4점 — `=지지_간격 * 하중_간격_비` 또는 고정 값 |
| `지지_반지름` · `노즈_반지름` | 만들 때의 두께로 정한 값 — 두께별 규칙(ISO 178)은 식으로 못 쓴다(치수 식에 조건문이 없다). 메모로 말한다 |
| `롤러_길이` | `=폭 + 10` |
| `변형률` · `마찰계수` · `처짐` | 해석 조건이 가리킨다 — `처짐 = 변형률 · (3L² − (L − Li)²) / (12h)`(3점이면 εL²/6h — D790 의 식, 하중 간격 1/3 이면 0.213εL²/h — D6272 의 식) |

**형상에 안 쓰이는 변수도 인자다.** `마찰계수` · `변형률` 은 조건만 바꾸고(형상은 같다), `처짐` ·
`지지_간격` 같은 **식 변수**는 인자가 아니라 따라간다 — DOE 화면은 식 변수를 인자 표에서 빼고 「식으로
정의된 변수」 로 보인다(숫자 칸에 넣으면 식이 글자로 서버에 가서 거절됐다). 편집기의 변수 패널은
입력란 · 다른 변수 · 해석 조건에서의 쓰임을 다 센다 — 조건 · 다른 변수가 쓰는 변수는 「미사용」 이
아니고, 지울 수 없다(2026-10-04 사용자 지적).

## 3. 굽힘 — 해석 조건 (4단계)

| 무엇 | 어떻게 |
| --- | --- |
| 롤러 · 노즈 | 파트별 설정 **강체** |
| 지지 롤러 | 원통면에 고정 지지 |
| 노즈 | 원통면에 원격 변위(강체) — Z = `=-처짐`, 나머지 0 |
| 접촉 | 시편 아랫면 ↔ 롤러, 시편 윗면 ↔ 노즈 — 마찰(`=마찰계수`), 비대칭, 접촉 상태로 조정 |
| 강체 운동 | 시편 아랫면 한가운데의 작은 원(`divide_face`, 태그 `시편_중앙`)을 X · Y 고정. 시편이 X · Y 로 대칭이라 그 자리는 원래 X · Y 로 안 움직인다 — 결과를 비틀지 않고, 접촉만으로 놓인 시편이 미끄러지는 것만 막는다 |
| 해석 | 정적, 대변형, 초기 부단계 20 |
| 물성 | **비워 둔다** — 사용자가 시편 물성을 고른다 |

## 4. 굽힘 지그 생성기

`JigOptions` 에 `bending_points`(3 · 4) · `bending_load_span` · `bending_preset` · `bending_setup`.
`bending_preset` 을 주면 서버가 프리셋(공개 · 사내)의 `setup` 을 `bending_setup` 에 값으로 채우고
(`works._jig_options`), 계획(`planning._bending_rule`)이 시편 템플릿과 **같은 규칙 함수**로 지지 간격 =
간격비 × 부품 두께(Z 높이), 반지름은 두께에 따라 정한다. 노즈는 목록(`plan.noses`)이고 4점이면 레시피
변수 `하중_간격` 하나로 둘이 함께 벌어진다. 화면 「지그 옵션」 의 굽힘에 「시험 규격」 · 「방식」.

## 5. 전자제품 — 제품 시험 (2026-10-05, 1단계)

휴대폰 · 가전 · TV 같은 전자제품의 규격 시험. 해석 쪽(SimEngBay)이 지금 푸는 것이 모달 · 정적 ·
조화 응답뿐이라, 그것으로 되는 시험부터 넣었다.

| 시험 | 규격(공개 프리셋) | 어디에 | 해석 |
| --- | --- | --- | --- |
| 보드 굽힘 | JESD22-B113 · IPC/JEDEC-9702 (보드 132 x 77 x 1.0, 지지 110 · 하중 75 mm) | 굽힘 프리셋(시편) | 정적 |
| 스마트폰 3점 굽힘 | 예시(공개 규격 아님) — 사내 규격으로 복사해 맞춘다 | 굽힘 프리셋 · 지그 생성의 굽힘 | 정적 |
| 정하중 | IEC 62368-1 부속서 T.2 ~ T.5 (10 · 30 · 100 · 250 N, 원형 접촉 12 · 30 mm 근사) | **제품에 건다** | 정적 |
| 정현파 진동 | IEC 60068-2-6 (10~150 Hz 1 g · 10~500 Hz 2 g · 10~2000 Hz 5 g) | **제품에 건다** | 조화 응답(모드 중첩) |

**제품 시험**(`core/specimens/product.py`, `POST /specimens/product-tests`, MCP
`apply_product_test`): 사용자의 부품(내 작업 · 공용 부품)에 건다. 형상을 새로 그리지 않고 **제품
레시피를 그대로** 쓴 새 작업 — 바디 이름이 같아 제품의 물성 · 접촉 · 파트별 설정이 그대로 맞는다.
구속 · 하중 · 초기조건 · 해석 설정만 시험의 것으로 바꾼다.

- 받침은 제품의 아랫면(-Z 를 향하는 평면, 고정 지지), 정하중은 윗면(+Z)을 누른다. 다른 면을
  시험하려면 제품을 돌려 저장한 뒤 건다. 자리를 못 찾으면(구처럼 평면이 없으면) 만들지 않고 말한다.
- 정하중: 윗면의 (X, Y)(비우면 가운데)에 접촉 지름의 원으로 면을 나누고(`divide_face`, 태그
  `시험_하중_자리`) 힘을 -Z 로. 진동: 한 축(X · Y · Z)으로 일정 가속도(`acceleration`), 조화 응답의
  주파수 범위 · 점 수 · 모드 수 · 감쇠비는 프리셋에서. 교차 주파수 아래의 변위 일정 구간은 나타내지
  않는다.
- 시험 변수는 레시피 변수다(`시험_하중` · `시험_지름` · `시험_X` · `시험_Y` · `시험_가속도_g`) — DOE 로
  하중 크기 · 누르는 자리 · 가속도를 훑는다. 이미 시험을 건 작업에는 다시 걸지 않는다(이름이 겹친다).
- 화면: 「시험 규격」 이 시험 종류마다 표로 나뉘고, 제품 시험 줄의 「제품에 적용」 이 제품을 고르게
  한다. 사내 규격 편집은 굽힘(`PresetDialog`)과 그 밖의 종류(`PresetFieldsDialog` — 칸은
  `kinds.ts` 의 정의) 두 창.

### 5.1 2단계 — 바로 풀 수 있는 시험 여섯 (2026-10-05)

모두 정적 · 모달이라 지금 해석 쪽에서 푼다. 공개 프리셋은 출처를 적고 `verified: false`.

| 시험 | 규격(공개 프리셋) | 어디에 | 해석 |
| --- | --- | --- | --- |
| 고유진동수 | IEC 60068-2-6 진동 응답 조사(10~150 · 500 · 2000 Hz) · ASTM E1876 자유-자유 | **제품** | 모달 |
| 인장 | ASTM E8(판재형 · 소형) · D638 Type I~V · ISO 527-2 1A · 1B(도그본), ASTM D3039 · ISO 527-5(띠) | 시편 | 정적 |
| 적층 압축 | ISTA 적재식 · ASTM D642 · ISO 12048(값은 예시) | **제품** | 정적 |
| 비틀림 | 공개 규격 없음 — 예시 6° · 10°, 사내 규격으로 복사해 정한다 | **제품** | 정적 대변형 |
| 손잡이·벽걸이 | IEC 62368-1 8.8 손잡이 · 8.7 벽 · 천장 고정(무게의 4배) | **제품** | 정적 |
| 전단 · 접착 이음 | ASTM D5379 · D7078(V 노치), ASTM D1002 · D5868 · ISO 4587(겹치기) | 시편 | 정적 |

**시편**(`tensile.py` · `shear.py` · `lap.py`, 공통 `coupon.py`): 그립은 바디로 그리지 않는다 — 양
끝의 윗면 · 아랫면을 면 나누기로 물린 자리로 표시하고(테두리에서 0.5 mm 띄운다) 거기에 구속을 바로
건다. 물린 면은 그립과 함께 움직이므로 접촉 없이 같은 결과이고 모델이 가볍다.

- 인장: 도그본은 평행부와 그립부를 반지름 R 의 호로 잇는다(호가 평행부에 접한다 — 전이부 길이
  `√(2Rh - h²)`, h = 폭 차이의 절반). 치수가 레시피 변수이고 전이부는 식이라 DOE 로 평행부 폭 ·
  반지름을 훑는다. 그립이 전이부를 물면 막는다(D638 Type V · E8 소형은 그래서 그립 길이를 규격보다
  조금 줄였다 — 메모). 표점 구간도 윗면에 나눠 둔다. 한쪽 그립 고정, 다른 쪽을 X 로 `늘림 = 변형률 x
  그립 간격`. 띠(D3039)의 탭은 그리지 않고 탭 자리를 그립으로 본다.
- 전단(V 노치): 뿌리 호가 양 빗변에 접한다. 노치 양쪽 반을 물어(`물림 간격` 이 전단 구간) 한쪽을
  고정하고 다른 쪽을 폭 방향(Y)으로 옮긴다.
- 겹치기 이음: 바디 셋(`피착재_1` · `접착층` · `피착재_2`), 접착층과 피착재는 본드 접촉. 대변형이
  기본(편심으로 돈다). 접착층 두께는 규격이 정하지 않으면 0.2 mm(해석 기본값).
- 시편 치수는 `SpecimenRequest.dimensions`(프리셋 `specimen` 의 칸 이름 → 값)로 바꾸고, 바꾼 값도
  프리셋과 같은 검사를 지난다(`specimens.resized`).
- 모양은 해석식으로 확인한다(`test_core_coupons.py` — 도그본 넓이, V 노치 넓이, 판 셋의 부피).

**제품 시험의 자리 — 3D 에서 고른다**(`FacePick` — 누른 점 · 법선 · 면 종류). 평면은 「이 방향을
보는 면 중 이 점에서 가장 가까운 것」(`normal` + `near`), 곡면은 「이 종류의 면 중 가장 가까운 것」
으로 적는다. 시험마다 고를 수 있는 자리(`product.FACE_SLOTS`):

| 시험 | 고정 면(`support`) | 그 밖 | 기본 |
| --- | --- | --- | --- |
| 정하중 | 고를 수 있다 | 누를 면(`load`, 평면 하나 — 그 면의 반대 방향으로 누른다, `시험_Z` 도 생긴다) | 아랫면 받침 · 윗면 하중(아랫면을 누르면 받침은 윗면) |
| 손잡이·벽걸이 | **꼭 고른다** | — | 무게의 배수가 -Z 로(위로 가속 — 밀도가 무게를 정한다) |
| 적층 압축 | — | 제품 무게(kg) **꼭 준다** | 아랫면 받침 · 윗면 전체 |
| 비틀림 | 고정 끝 | 비트는 끝(`twist`) | 긴 축(또는 `axis`) 양 끝의 평면. 끝이 둥글면 안쪽 면을 집지 않게 거절하고 고르라고 말한다 |
| 진동 · 고유진동수 | 고를 수 있다 | — | 아랫면. 자유-자유는 구속 없음(강체 모드 6개를 더해 구한다) |

화면은 「고르기」 를 누를 때 한 번 제품을 그려(`POST /specimens/product-mesh`) 3D 에 띄우고, 면을
누르면 담고 다시 누르면 뺀다. 적층 압축의 하중은 `무게 · g · (단수 - 1) · 계수` 또는 `무게 · g ·
(적재 높이 - 제품 높이) / 제품 높이 · 계수` 로 레시피 변수(`시험_하중`)다.

**2단계 이후 — 해석 쪽이 지원해야 한다**: 낙하(IEC 60068-2-31 · IEC 62368-1 T.7) · 강구 · IK
충격(IEC 62368-1 T.6 · IEC 62262) · 반정현파 충격(IEC 60068-2-27 · JESD22-B111)은 동적(explicit ·
과도) 해석, 랜덤 진동(IEC 60068-2-64 · ASTM D4169)은 PSD 해석이 필요하다. CompCore 쪽은 낙하 ·
충격 지그(자세 · 낙하물)에 초기 속도 · 바닥 · 접촉 조건을 붙이면 된다(조건 모델에 `explicit` 이
이미 있다). TV · 가전의 안정성(기울임 · 수평력)은 강체 계산이라 해석 대신 계산으로 넣는 편이 낫다.

### 5.2 3단계 — 시편 · 제품 시험 일곱 (2026-10-05)

| 시험 | 규격(공개 프리셋) | 어디에 | 해석 |
| --- | --- | --- | --- |
| 숏빔 전단 | ASTM D2344(4:1) · ISO 14130(5:1) | 굽힘 프리셋(시편) | 정적 |
| 압착 | IEC 62133-2 · UN 38.3 T.6 (13 kN) | **제품** — 평판 둘 사이 | 정적 |
| 수압 | IEC 60529 IPX7(1 m) · IPX8(1.5 · 6 m 예시) | **제품** — 바깥 면 전체 | 정적 |
| 등가 정적 가속도 | IEC 60068-2-27(15 · 50 · 100 g) · ISO 16750-3(500 m/s²) | **제품** — 받침 고정, 한 축 | 정적(충격의 근사) |
| 방향 하중 | IEC 60335-1 코드 고정(30 · 60 · 100 N + 모멘트) · USB Type-C 렌칭(2.0 · 3.5 N·m) | **제품** — 고른 면 | 정적 |
| 구멍 · 핀 시편 | ASTM D5766 오픈홀 인장 · D6484 오픈홀 압축 · D5961 핀 베어링 · D7332 뽑힘(예시) | 시편 | 정적 |
| 압축 시편 | ASTM D695 · ISO 604(각기둥) · E9(원기둥) · D6641 · ISO 14126(띠) | 시편 | 정적 |

- **압착**: 기본은 윗면 전체를 누르고 아랫면이 받침. 3D 에서 옆면을 고르면 받침은 그 반대쪽 끝
  면이다(「-법선을 보는 면 중 반대쪽 끝에서 가장 가까운 것」 — 끝에 있는지 서버가 확인).
- **수압**: 수심 x 0.00980665 MPa(물 1 m = 9.807 kPa) x 계수를 모든 면(또는 고른 바깥 면)에
  `direction: "normal"` 로. 수압은 스스로 평형이라 받침은 강체 운동만 막는다. 속이 빈 제품 · 조립은
  안쪽 · 맞닿은 면에도 걸리므로 바깥 면만 고르라고 메모로 말한다. 「모든 면」 은 near 없는 선택이라
  목록 상한(60)에 잘리지 않는다.
- **등가 가속도**: 충격(반정현파)을 정적 가속도 g x 배율로 근사 — **동적 해석이 아니다**. 응답
  배율은 고유진동수와 지속 시간에 따라 다르고(반정현파 최대 약 1.7), 기본 배율은 1 이다. 한 축
  +방향으로 가속(관성력은 -방향) — 반대 방향은 선형이면 응력 부호만 바뀐다.
- **방향 하중**: 고른 면에 힘(N)과 모멘트(N·m → 조건에는 N·mm, `=시험_토크 * 1000`)를 같은
  방향(힘의 방향 = 모멘트 축)으로. 방향을 비우면 고른 평면에서 바깥으로(당김), 곡면을 고르면 방향을
  꼭 정한다. 화면은 당김 · 누름 · ±X/Y/Z 를 고르게 한다.
- **구멍 · 핀 시편**: 오픈홀은 인장 · 압축 띠에 가운데 구멍(표점 구간이 구멍을 감싼다). 핀 베어링은
  강체 핀이 구멍 가장자리를 가까운 끝 쪽으로 민다(이중 전단 지그의 근사, 마찰 접촉). 뽑힘은 판
  둘레의 위아래 고리(스케치 고리로 나눈 면 — `near` 는 면 중심으로 재므로 가운데가 같은 고리는
  따로 나눠야 한다)를 고정하고 체결구를 아래로 당긴다(머리와 판 마찰 접촉, 몸통과 구멍은 닿지 않음).
  D7332 의 치수는 찾지 못해 예시값이다.
- **압축 시편**: 각기둥 · 원기둥은 세워서 아랫면 고정 · 윗면을 아래로(옆으로는 막는다 — 마찰이 큰
  가압판), 띠 · 구멍 띠는 그립으로 X 를 누른다. 좌굴 · 좌굴 방지 지그는 보지 않는다(좌굴 해석이
  필요).
