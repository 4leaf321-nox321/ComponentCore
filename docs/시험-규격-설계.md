# 시험 규격 — 시편 · 시험 지그 · 해석 조건을 규격 프리셋으로

SpaceClaim 애드인(71_AnsysJigAutoModeler)에 있던 시험 시편 · 시험 지그 프리셋(약 58종)을 CompCore 로
옮기는 일의 설계와 진행. 공개 규격은 코드, 사내 규격은 DB 에 같은 모양으로 둔다(ADR 0006).
굽힘을 「시편 → 시험 지그 → 해석 조건」 까지 끝까지 먼저 하고(2026-10-04), 나머지 시험을 같은 길로
더한다.

## 0. 애드인에 있던 것 (2026-10-04 조사)

| 분류 | 애드인의 종류 | 여기서 |
| --- | --- | --- |
| 굽힘 시편 · 지그 | 3점 7(D790 16:1 · 32:1, ISO 178, D7264, C1161 A · B, DMA) · 4점 5(D6272 16:1 · 32:1, C1161 B · C, DMA) | ✅ 13종(D7264 B 더함) |
| 인장 · 전단 시편 | 25종(E8, D638 I~V, ISO 527-2, E602, D5766, D3039, IPC-TM-650, D5379, D7078 …) + 그립 | 다음 |
| 압축 / CAI | 6 / 3 + 가압판 · 좌굴 방지 가이드 | 그다음 |
| 피로 / 접착 이음 | 6 / 5 | 그다음 |
| 나사 | ISO 262 M1.6~M24(지름 · 피치), 머리 · 너트 · 와셔는 비례 근사 | 레시피의 나사 표(M3~M12, 너트 · 와셔는 실제 표)를 넓힌다 |
| 재료 | 3종 기본값 | **안 옮긴다** — MatNexus · 물성 카탈로그가 있다 |

애드인의 값 일부는 규격과 달라 보였다(D638 Type II 필렛 R12.7 ↔ R76, ISO 527-2 1B R20 ↔ R60, D1002
겹침 25.4 ↔ 12.7, D790 롤러 Ø8 ↔ R5). 그대로 옮기지 않는다 — 프리셋마다 출처를 적고 규격서와
대조하기 전에는 「검토 필요」.

## 1. 프리셋

```jsonc
{
  "id": "astm-d790-16",               // 공개 규격은 이름, 사내 규격은 DB 의 uuid
  "test": "bending", "family": "bend_bar",
  "standard": "ASTM D790", "name": "ASTM D790 3점 굽힘 (16:1)",
  "specimen": {"length": 127, "width": 12.7, "thickness": 3.2},
  "setup": {
    "points": 3,
    "span": {"to_thickness": 16},       // 또는 {"value": 40}
    "load_span": null,                  // 4점: {"to_span": 0.3333} 또는 {"value": 20}
    "support_radius": 5.0,              // 또는 [{"max_thickness": 3, "radius": 2}, {"radius": 5}]
    "nose_radius": 5.0,
    "overhang": {"to_span": 0.1, "min": 6.4}
  },
  "analysis": {"strain": 0.05, "friction": 0.1},   // 해석 기본값 — 규격의 판정 기준이 아니다
  "source": "ASTM D790: …", "verified": false, "note": ""
}
```

- 정본은 `core/specimens/presets.py`(pydantic). 시편 길이가 지지 간격 + 양쪽 돌출을 못 담으면, 4점인데
  하중 간격이 없으면, 두께별 반지름의 마지막 줄이 나머지를 안 맡으면 거절한다.
- 공개 규격: `core/specimens/data/bending.json`. 값을 고치면 `source` 를 같이 고치고, 규격서와
  대조했으면 `verified: true`. **회사 · 고객 규격은 여기에 넣지 않는다** — 저장소가 공개다.
- 사내 규격: `specimen_presets`(0034). 화면 「시험 규격」 에서 관리자가 공개 규격을 복사해 고친다.

## 2. 굽힘 — 시편 · 시험 지그

좌표: 시편 길이 X · 폭 Y · 두께 Z, XY 가운데가 원점, 아랫면 z=0. 지지 롤러는 아래(축 Y, 아랫면에
닿게), 노즈는 위. 바디 이름은 `시편` · `롤러_1` · `롤러_2` · `로딩_노즈`(4점: `로딩_노즈_1` · `_2`)
— 지그 생성기의 이름표와 같다.

레시피 변수가 규칙을 든다 — **DOE 가 두께를 훑으면 따라온다**:

| 변수 | 값 |
| --- | --- |
| `길이` · `폭` · `두께` | 시편 |
| `간격비` · `지지_간격` | `=간격비 * 두께`(간격비 규격) 또는 고정 값 |
| `하중_간격_비` · `하중_간격` | 4점 — `=지지_간격 * 하중_간격_비` 또는 고정 값 |
| `지지_반지름` · `노즈_반지름` | 만들 때의 두께로 정한 값 — 두께별 규칙(ISO 178)은 식으로 못 쓴다(치수 식에 조건문이 없다). 메모로 말한다 |
| `롤러_길이` | `=폭 + 10` |
| `변형률` · `마찰계수` · `처짐` | 해석 조건이 가리킨다 — `처짐 = 변형률 · (3L² − (L − Li)²) / (12h)`(3점이면 εL²/6h — D790 의 식, 하중 간격 1/3 이면 0.213εL²/h — D6272 의 식) |

**형상에 안 쓰이는 변수도 인자다.** `마찰계수` · `변형률` 은 조건만 바꾸고(형상은 같다), `처짐` ·
`지지_간격` 같은 **식 변수**는 인자가 아니라 따라간다 — DOE 화면은 식 변수를 인자 표에서 빼고 「식으로
정의된 변수」 로 보인다(숫자 칸에 넣으면 식이 글자로 서버에 가서 거절됐다). 편집기의 변수 패널은
입력란 · 다른 변수 · 해석 조건에서의 쓰임을 다 센다 — 조건 · 다른 변수가 쓰는 변수는 「미사용」 이
아니고, 지울 수 없다(2026-10-04 사용자 지적).

## 3. 굽힘 — 해석 조건 (4단계)

| 무엇 | 어떻게 |
| --- | --- |
| 롤러 · 노즈 | 파트별 설정 **강체** |
| 지지 롤러 | 원통면에 고정 지지 |
| 노즈 | 원통면에 원격 변위(강체) — Z = `=-처짐`, 나머지 0 |
| 접촉 | 시편 아랫면 ↔ 롤러, 시편 윗면 ↔ 노즈 — 마찰(`=마찰계수`), 비대칭, 접촉 상태로 조정 |
| 강체 운동 | 시편 아랫면 한가운데의 작은 원(`divide_face`, 태그 `시편_중앙`)을 X · Y 고정. 시편이 X · Y 로 대칭이라 그 자리는 원래 X · Y 로 안 움직인다 — 결과를 비틀지 않고, 접촉만으로 놓인 시편이 미끄러지는 것만 막는다 |
| 해석 | 정적, 대변형, 초기 부단계 20 |
| 물성 | **비워 둔다** — 사용자가 시편 물성을 고른다 |

## 4. 굽힘 지그 생성기

`JigOptions` 에 `bending_points`(3 · 4) · `bending_load_span` · `bending_preset` · `bending_setup`.
`bending_preset` 을 주면 서버가 프리셋(공개 · 사내)의 `setup` 을 `bending_setup` 에 값으로 채우고
(`works._jig_options`), 계획(`planning._bending_rule`)이 시편 템플릿과 **같은 규칙 함수**로 지지 간격 =
간격비 × 부품 두께(Z 높이), 반지름은 두께에 따라 정한다. 노즈는 목록(`plan.noses`)이고 4점이면 레시피
변수 `하중_간격` 하나로 둘이 함께 벌어진다. 화면 「지그 옵션」 의 굽힘에 「시험 규격」 · 「방식」.

## 5. 남은 것

- **값 대조** — 13종 모두 `verified: false`. 규격서를 가진 쪽에서 대조하고 코드를 고친다(화면에서는
  사내 규격으로 복사해 바로 쓸 수 있다).
- 다음 시험: 인장(도그본 · 노치 · 구멍 띠 · V 노치 전단 + 그립) → 압축 · CAI(가압판 · 좌굴 방지
  가이드) → 피로 · 파괴 · 접착 이음. 같은 길(프리셋 모델 · 생성기 · 데이터 파일 · 조건)이다.
- 나사 표 M1.6~M24 · 피치 · 실제 볼트 머리 표(ISO 4762 · 4017) — 구멍 띠 시편과 함께.
